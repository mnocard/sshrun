Команды

Enterвыполнить следующий шаг / продолжить после паузы
<сервер> <команда>выполнить команду на сервере (сервер1,сервер2 — на нескольких)
all <команда>выполнить на всех серверах
upload <сервер|all> <локальный> <удалённый>загрузить файл или каталог
edit <сервер> <файл>открыть файл во встроенном редакторе (или кнопка ✎ у сервера)
repeat [N]повторить шаг N (по умолчанию — последний/упавший)
retryпосле ошибки — продолжить шаг с места остановки
skipпосле ошибки — игнорировать и идти дальше
goto Nперейти к шагу N и выполнить его
break <сервер>Ctrl+C команде на сервере
status / serversсписок серверов и их адресов
quitзавершить программу
